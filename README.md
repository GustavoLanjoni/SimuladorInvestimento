# 💰 Simulador de Investimentos - Java com Interface Gráfica

Projeto simples e funcional feito com **Java + Swing** que simula o crescimento de um investimento com base no valor inicial, taxa de juros mensal e quantidade de meses.

## ✨ Funcionalidades

- Entrada de valor inicial, taxa de juros mensal e número de meses
- Cálculo de juros compostos mês a mês
- Exibição do resultado em área de texto formatada
- Resumo final com montante e lucro total
- Botão para limpar os campos e iniciar nova simulação
- Interface amigável e intuitiva

## 🛠 Tecnologias Utilizadas

- Java 8+
- Swing (Java GUI)
- IDE recomendada: VS Code ou IntelliJ IDEA
